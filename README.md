# 杭州二手房探索性数据分析
## 项目简介
本项目基于杭州二手房模拟数据集，使用Python完成完整的探索性数据分析。使用Pandas进行数据清洗，处理缺失值、重复值，并对楼层等分类特征进行数值编码；利用matplotlib、seaborn绘制直方图、箱线图、散点图、热力图，使用IQR方法剔除房价异常样本，分析各特征与房价的相关关系，挖掘杭州二手房价格分布规律。

## 项目环境
Python, pandas, seaborn, matplotlib, numpy
依赖包查看：requirements.txt

## 分析流程
1. 数据读取与概览
2. 数据清洗：处理缺失值、去除重复值、异常值剔除
3. 特征工程：楼层分类特征编码
4. 可视化分析：散点图、箱线图、直方图、相关性热力图
5. 相关性分析与业务结论

## 主要结论
1. 房屋面积和房价呈现中等程度正相关，面积越大，房价整体越高。
2. 房价分布呈右偏，大部分房源价格集中在中低区间，少量高价房源拉高整体分布。
3. 楼层与房价线性相关性较弱，不能单纯依靠楼层判断房价。
